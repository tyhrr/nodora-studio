# NODORA Studio — Personal Site

A personal portfolio / studio site for Alan Salva (NODORA). Built with plain HTML, CSS and JavaScript, with Font Awesome and Google Fonts. No build step — open `index.html` and you're done.

## Run it locally

```bash
git clone https://github.com/tyhrr/About-Me-exercise.git
cd About-Me-exercise
# open index.html in your browser
```

## Project layout

```
About-Me-exercise/
├── index.html
└── assets/
    ├── styles/    # main stylesheet
    ├── scripts/   # JS
    ├── img/       # images
    └── navbar/    # navbar partials
```

- The repo name is a leftover from when this was an exercise; the site itself is my personal studio page.
